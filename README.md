# 메뉴 정리 설치 안내

## 올릴 파일 위치

- `index.html` → 저장소 루트 (덮어쓰기)
- `default.html` → `_layouts/default.html`로 이름 바꿔서 덮어쓰기
- `sitemap.xml` → 저장소 루트 (덮어쓰기)
- `book/privacy/index.html` → `book/privacy/` 폴더를 새로 만들어서 그 안에
- `book/terms/index.html` → `book/terms/` 폴더를 새로 만들어서 그 안에

## 바뀐 내용

**상단 메뉴**: Home / 작가 소개 / 저서 / 작가SSUL / 갤러리 / 자유게시판 / BookText
(Facebook, 문의게시판 제거)

**하단(푸터)**: 문의게시판 / 개인정보처리방침 / 이용약관
개인정보처리방침과 이용약관은 아직 내용이 없어 "준비 중입니다" 안내만 있는
빈 페이지로 만들어뒀습니다. 나중에 내용이 정해지면 각 페이지 파일 안의
문구만 채워 넣으면 됩니다.

Facebook 링크는 이번에 메뉴에서 뺐습니다. 필요하시면 나중에 하단이나
다른 자리에 다시 넣어드릴 수 있습니다.
