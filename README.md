# 갤러리 기능 설치 안내

## 올릴 파일 위치

- `index.html` → 저장소 루트 (기존 파일 덮어쓰기) — 상단 메뉴에서 '작가 대표 사이트' 제거, '갤러리' 메뉴 추가
- `default.html` → `_layouts/default.html`로 이름 바꿔서 덮어쓰기 — 위와 동일한 메뉴 변경 (작가SSUL·갤러리 페이지 상단 메뉴용)
- `sitemap.xml` → 저장소 루트 (기존 파일 덮어쓰기) — 갤러리 페이지 주소 추가
- `_data/gallery.yml` → 저장소 루트의 `_data` 폴더 (새로 만들어서 그 안에 넣기)
- `book/gallery/index.html` → 저장소의 `book` 폴더 안에 `gallery`라는 새 폴더를 만들고, 그 안에 이 파일을 넣기

## 사진은 어디에 올리나요

저장소 루트에 `images` 폴더가 이미 있다면, 그 안에 `gallery`라는 폴더를 새로 만들고 사진 파일을 올려주세요.

```
images/
└─ gallery/
    ├─ gallery-01.jpg
    ├─ gallery-02.jpg
    └─ ...
```

## 사진을 갤러리에 등록하는 방법

`_data/gallery.yml` 파일을 열어서, 맨 아래 `[]` 를 지우고 아래 형식으로 사진마다 한 칸씩 추가하세요.

```yaml
- file: gallery-01.jpg
  alt: "화천 저수지 앞 가을 단체 사진"
  caption: "지난주 어르신들과 다녀온 가을 소풍입니다. 단풍이 유난히 붉었던 하루였습니다."
- file: gallery-02.jpg
  alt: "화천시니어클럽 사업단 작업 현장"
  caption: "사업단 어르신들이 실제로 일하는 모습입니다."
```

- `file` — images/gallery/ 폴더에 올린 실제 파일명 (대소문자까지 정확히 일치해야 합니다)
- `alt` — 대체 텍스트. 화면을 못 보는 분들을 위해 스크린 리더가 읽어주는 설명이자, 검색엔진이 사진 내용을 파악하는 데도 쓰입니다. "사진1" 같은 대충 쓴 말고, 실제 내용을 짧게 적어주세요.
- `caption` — 사진을 눌러 크게 볼 때 아래에 나오는 설명글입니다. alt보다 조금 더 자세히 적으셔도 됩니다.

파일을 저장하실 때는 반드시 UTF-8 인코딩으로 저장해 주세요.

이렇게 등록하면 `book/gallery/index.html` 파일을 전혀 손대지 않아도, 저장하신 순서(목록 위에서부터) 그대로 화면에 썸네일이 나타나고, 4장씩 한 줄로 자동 배치됩니다. 썸네일을 누르면 사진이 크게 보이면서 caption이 아래에 함께 나옵니다.
