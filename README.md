# 게시판 3개 (우리 메뉴 유지) 설치 안내

## 올릴 파일 위치

- `index.html` → 저장소 루트 (덮어쓰기)
- `default.html` → `_layouts/default.html`로 이름 바꿔서 덮어쓰기
- `sitemap.xml` → 저장소 루트 (덮어쓰기)
- `book/board/free/index.html` → `book/board/free/` 폴더를 새로 만들어서 그 안에
- `book/board/booktext/index.html` → `book/board/booktext/` 폴더를 새로 만들어서 그 안에
- `book/board/contact/index.html` → `book/board/contact/` 폴더를 새로 만들어서 그 안에

## 작동 방식

메뉴에서 '자유게시판' 등을 누르면, 이제 dothome 주소로 바로 이동하지 않고
우리 사이트의 새 페이지(예: shinbook.kr/book/board/free/)가 먼저 열립니다.
이 페이지는 우리 사이트 메뉴(상단바)를 그대로 유지한 채, 그 아래에
워드프레스 게시판 화면을 끼워 넣고, 워드프레스 자체의 상단 메뉴 부분만
위로 살짝 잘라서 가리는 방식입니다.

## 확인이 꼭 필요한 부분

- 실제로 열어봤을 때 워드프레스 상단 메뉴가 완전히 안 가려지거나, 반대로
  너무 많이 가려서 게시판 내용 일부가 잘리면, 각 페이지 파일 안의
  `top:-84px`와 `height:calc(100% + 84px)`의 숫자 84를 함께 조금씩
  줄이거나(예: 70) 늘려서(예: 100) 맞추면 됩니다. 원하시면 실제 화면을
  캡처해서 보내주세요. 정확한 숫자로 다시 맞춰드리겠습니다.
- 혹시 게시판 화면 자체가 아예 하얗게 비어 보이면, dothome 워드프레스 쪽에서
  '다른 사이트 안에 넣기(프레임)'를 막아두었을 가능성이 있습니다. 이 경우
  이 방식 대신 각 페이지에 있는 '여기를 눌러 새 창에서 열어주세요' 링크로
  안내하는 방법으로 바꿔야 합니다.
